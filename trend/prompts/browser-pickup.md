# ブラウザ操作でトークテーマを集めるプロンプト

Claude for Chrome（ブラウザ操作）で使う用。ログイン済みの Chrome から
Threads と X の検索画面を直接見にいくので、鍵も課金もなしに「直近1ヶ月」の条件を満たせる。

## 使う前に

- Chrome で Threads（threads.com）と X（x.com）にログインしておく
- 収集結果を貼るための Google ドキュメントを開いておく（任意）

## 貼り付けるプロンプト

以下をそのまま貼る。日付と件数は必要に応じて書き換える。

---

Instagram で発信している Mai さんという方のリール企画のために、
X と Threads でバズっている投稿を集めて、トークテーマを10本にまとめてほしい。

## Mai さんについて

- 5人の子を育てるママ経営者（40歳）。ビューティーパウダー®の開発者
- 借金1,300万円のどん底主婦から、起業2年で海外へ。Remieブランドを全国2,000店舗に展開
- 日本とドバイで3社の代表。女性変革コミュニティ RHC を主催
- 離婚・再婚を経てステップファミリー。5人目は40歳のときにドバイで出産
- 発信の軸は「女性の経済的自立」。夫に依存して生きてきた女性、
  環境が整ってから動こうとする女性に、正面から問いを投げるスタンス

## 集める条件

- 対象：Threads と X の日本語投稿
- 期間：直近1ヶ月以内
- エンゲージメント：いいね1,000件以上
- テーマ：次の4つを中心に
  - 夫婦のあり方・夫婦の価値観（家事分担、夫への期待、離婚、産後クライシス）
  - 子育て（ワンオペ、育児と仕事の両立、保育園、預けることへの罪悪感）
  - 妊活（不妊治療、高齢出産、出産の体験）
  - 女性の働き方・女性の自立（専業主婦、扶養、ワーママ、時短、起業）
- 特に**賛否が割れてコメントが伸びている投稿**を優先する。
  いいね数よりコメント数の比率が高い投稿ほど、リールの題材として価値が高い

## 集め方

1. Threads（threads.com）の検索を開き、上のテーマのキーワードで検索する。
   「育児」「ワンオペ」「夫に期待」「専業主婦」「家事分担」「妊活」「高齢出産」
   「女性の自立」「共働き」「保育園」あたりから、10〜15語ほど試す
2. 検索結果は**「最近」タブに切り替えて**、直近1ヶ月のものだけを見る
3. いいね1,000件以上のものを開き、投稿者名・投稿日・いいね数・コメント数・本文・URL を控える
4. X（x.com）でも同じキーワードで検索する。
   検索欄に `キーワード min_faves:1000 lang:ja since:YYYY-MM-DD` と入れると一発で絞れる
5. 20〜30件ほど集まったら、そこから10本に絞る

## 出力してほしい形

10本それぞれについて、次の5つを書いてほしい。

1. **見出し** — 元投稿の主張を一文で
2. **元投稿** — @ユーザー名／媒体／投稿日／いいね数／コメント数／URL
3. **議論のポイント** — なぜ伸びたのか、コメント欄でどこの意見が割れているか
4. **Mai さんの切り口** — 次のどの軸で語るかを、具体的に3〜5行で
   - 経済的自立 ―「夫に文句を言う前に自分で稼ごう」
   - 期待しない哲学 ―「期待するから不満が出る。初めから期待しなければいい」
   - 頼ることへの寛容さ ― 日本は「預ける＝良くない」、ドバイは人に頼るのが当たり前という対比
   - 修羅場の実績 ― 借金1,300万・離婚・ステップファミリー・5児・40歳で出産
   - 他責から自責へ ―「環境のせいにして止まっている女性」への問いかけ
5. **フック案 3本** — リール冒頭の1行。次の3原則のどれかに沿って作る
   - 「あなた」への宣告に変える（体験談の主語を視聴者に向ける）
   - 仮想敵の行動を冒頭で指摘する（「旦那の収入に依存している女性」など）
   - 逆説・断言・禁止で違和感をつくる

   例：「旦那の収入に期待してる女性は人生墜落します」「お母さんは頑張るな」
   「5人の子持ち、離婚してマジで良かったです」

10本はテーマが偏らないよう、夫婦／子育て／妊活／働き方の4分野に散らしてほしい。

## 守ってほしいこと

- いいね数・コメント数・投稿日・ユーザー名は、**画面で見えた数字をそのまま書く**。
  推測で埋めたり、丸めたりしない
- 条件を満たす投稿が10件に届かなかったら、届かなかったと正直に書く。
  古い投稿を直近のものとして混ぜない
- 集めている途中でも、見つけた投稿は都度メモしておいて、
  最後にまとめて失われないようにする

---

## 補足

- 集め終わったら「この10本を Google ドキュメントにまとめて」と追加で頼めば、
  そのまま資料の形にできる
- 毎月回すなら、実行した日付と結果を `data/` に残しておくと、
  同じ論点が何度もバズっているか（＝繰り返し使える鉄板ネタか）が追える
