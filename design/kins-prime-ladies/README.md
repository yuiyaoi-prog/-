## ターゲットと導線

- 35歳以上の女性。便通・ぽっこりお腹・肌のゆらぎ・だるさなど、複数の不調を抱えて「腸活」で検索してたどり着く層
- フック: **腸内フローラ検査 ¥0**（先着1,000名のモニター枠）
- CTA: すべて**公式LINEへの1本化**。購入ではなく友だち追加がゴール
- 離脱防止に、スマホでは画面下に常時CTAバーを固定

## 構成

1. ヒーロー — 「その不調、『がんばり不足』じゃなくて腸内フローラのせいかも。」＋無料訴求
2. 悩みチェックリスト（タップで自己診断／3つ以上でCTAが出る）
3. なぜ35歳からなのか（多様性・ホルモン・短鎖脂肪酸）
4. 「体にいい腸活」より「私に合う腸活」を — よくある空回りの否定
5. 結果レポートのサンプル（スコア・菌の構成比・食材提案）
6. 3ステップ（LINE登録 → 採取・投函 → 結果）
7. なぜ無料なのかの説明
8. お客様の声 / FAQ / クロージングCTA

## トンマナ

黒 → **プラムブラック＋モーヴ寄りのウォームオフ白**へ。PRIME本体の緊張感は残しつつ、
"クリニック感"にも"ゆるふわウェルネス感"にも寄せないラインを狙っています。

| ロール | 値 |
| --- | --- |
| 地 | `#F6F1F0`（ダーク時 `#1E1418`） |
| インク | `#33222B` |
| アクセント | `#9A3F5E` マルベリー |
| 補助 | `#B98726` 発酵ゴールド / `#6E8161` モス |
| CTA | LINEグリーン `#06C755` |

- 見出しは**明朝**、本文はゴシック、ラベル・数値はレタースペースしたラテン
- 装飾の核は**腸内フローラのリング**。検査結果の円グラフをそのままブランドの図像に転用し、
  ヒーローでゆっくり回転させています（`prefers-reduced-motion` で停止）
