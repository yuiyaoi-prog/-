初稿からの主な変更:

- **明朝をやめてA1ゴシック系に**（KINSは意図して明朝を使っていない）

- **PRIMEのグラデーションという「所作」だけ継承し、色相をKINSの暖色に回転**。
  見出し・数値・メーター・罫にこのグラデを通し、PRIMEのサブブランドとして読めるようにした

- 35歳以上の女性。便通・ぽっこりお腹・肌のゆらぎ・だるさなど複数の不調を抱えて「腸活」で検索してたどり着く層
- フック: **腸内フローラ検査 ¥0**（先着1,000名のモニター枠）
- CTAは**公式LINEに一本化**。購入ではなく友だち追加がゴール
- スマホは画面下に常時CTAバーを固定

1. ヒーロー — 「その不調、『がんばり不足』じゃなくて腸内フローラのせいかも。」
2. 悩みチェックリスト（タップで自己診断／3つ以上でCTAが出る）
3. なぜ35歳からなのか（α多様性・ホルモン・酪酸）
4. みえる→わかる→かわる（可視化 / 実感設計 / 伴走）
5. 「体にいい腸活」より「私に合う腸活」を
6. 検査でわかること（実サイトの4項目）
7. 結果レポートのサンプル
8. 3ステップ → なぜ無料か → お客様の声 / FAQ / クロージング
