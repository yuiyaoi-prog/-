# Mai さん リール用トークテーマ 10選（2026-08-05 収集）

## この回の収集条件と、実際に取れたもの

- 目標条件：直近30日以内 / いいね1,000件以上
- **実際：この条件を満たす投稿は0件だった**

理由は収集経路にある。今回は API キーなしで動かせる「検索エンジン経由」で候補を集めたが、
検索インデックスが数週間〜数ヶ月遅れるため、直近1ヶ月の投稿がそもそも引っかからない。
候補64件を取得して、直近45日以内だったのは3件だけだった。

そこで今回は**期間の条件だけ外し、いいね1,000件以上の18件から10本を選んだ**。
各投稿のいいね数・返信数・投稿日は、すべて公開エンドポイントから取った実測値で、推測値は入っていない。

「直近1ヶ月」を毎回きちんと満たすには discovery を有料スクレイパ（月数百円）か
Meta 公式 API に切り替える必要がある。詳細は `trend/README.md`。

なお、ここで挙げた投稿の多くは半年〜1年前のものだが、
**同じ論点が繰り返しバズり続けているテーマ**なので、リールの題材としては現役で使える。
